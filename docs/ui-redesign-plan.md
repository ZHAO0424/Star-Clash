# 网页版菜单 UI/UX 重构 · Plan（2026-11-20，待批注，don't implement yet）

> 依据：`docs/ui-redesign-research.md`。范围同上：标题、主页、备战、卡组、联机、图鉴、设置。

## 0. 第一性原理：开战前玩家要做的只有四件事

1. **认出这是什么游戏**：品牌、氛围、阵营。只需要 1 秒，不需要一个独立的页面。
2. **最快开一局**：一次点击。
3. **可选地决定这一局**：我是谁（阵营、卡组）、在哪打（战场）、和谁打（电脑难度或好友）。
4. **其余**：查卡（图鉴）、调设置。随时可去，但不抢主操作的注意力。

由此推出三条设计约束，下面每个决定都从这三条出发：
- **一屏一个主操作**：视觉权重只有一个最高点。
- **层级靠字体和框的厚度表达，不靠颜色种类**：全站一套组件，三档厚度。
- **“设置一局”是一件事，放一屏**：不再拆成「备战」和「联机」两页。

## 1. 设计语言：「指挥台」

> **2026-11-20 按批注修订（视觉稿 v0.3–v0.4，以 `mockup/index.html` 为准）**：暗色衬线的“古典指挥台”与游戏的卡通美术不匹配，已改为**跟随字标和游戏自带材质**：
> - 字体：全站展示字改用**思源黑体 Black（Noto Sans SC 900）**，与字标同类厚重字形；不再使用思源宋体与 Cinzel。
> - 材质：按钮用游戏自带的**金色珐琅（主）/ 蓝色珐琅（联机、加入）/ 紫石板 + 金边（其余）**；面板 = 紫石板底 + 金色内边 + 深紫粗描边 + 立体底边（同字标底板）；去掉古典角饰。
> - 交互反馈：按钮统一“3px 深紫描边 + 6px 立体底边”，按下下沉 4px。
> - 文案：去掉按钮下和设置项下的说明小字；保留玩法必需信息（阵营特性、战场说明、卡牌描述）。
> 下文 1.1–1.4 中与此冲突的条目以本修订为准。

用 RTS 的**战争议事厅**作隐喻：菜单是一张镶金的指挥台，按钮是嵌在台上的铭牌，面板是锻造金属框。科幻题材，所以材质用**深色锻钢 + 金色描边 + 晶体辉光**，不用羊皮纸和木头。原创设计：只借鉴 RTS 的结构原则，不复制任何游戏的素材、字形或界面。

### 1.1 字体（两层）

| 层 | 用途 | 中文 | 英文 | 来源 |
|-|-|-|-|-|
| 展示字 | Logo 之外的所有标题、按钮、阵营名、数值大字 | 思源宋体 Heavy（Noto Serif SC 900） | Cinzel 700（全大写，古典铭刻感） | OFL，自托管，**只保留实际用到的字**做子集 |
| 正文字 | 说明、标签、卡面描述 | 思源黑体 Medium / Regular（Noto Sans SC 500/400） | Inter 400/600 | 同上；或退回系统字体（见批注点 C） |

- 子集脚本 `tools/subset-fonts.py`：从 `js/i18n.js` + `js/cards.js` + `index.html` 收集用字，生成 woff2。预计每个中文子集 80–200KB；展示字只在菜单用，进对局前懒加载正文字之外的字重。
- `font-display: swap`：字体没到时先用系统字，不阻塞首屏。

### 1.2 字号阶梯（全站只用这 8 级）

| Token | 桌面 | 手机 | 用途 |
|-|-|-|-|
| `--t-display` | 72 | 40 | 页面主标题（备战、图鉴…） |
| `--t-h1` | 44 | 30 | 区块大标题、主按钮 |
| `--t-h2` | 28 | 22 | 面板标题、阵营名 |
| `--t-h3` | 20 | 18 | 次级按钮、卡名 |
| `--t-body` | 16 | 15 | 正文、说明 |
| `--t-small` | 14 | 14 | 辅助信息、标签 |
| `--t-caption` | 12 | 12 | 只给数字角标、版权；**中文不低于 14** |
| `--t-overline` | 13（字距 +0.12em，全大写 / 中文加宽） | 12 | 分区小标签（如「战场」「对手」） |

字重只用 400 / 600 / 900 三档。行高：标题 1.15，正文 1.55。

### 1.3 颜色（约 14 个 token，取代现在的 310 个色值）

| 组 | Token |
|-|-|
| 底 | `--bg-0` 近黑紫 #120E18 · `--bg-1` 面板 #1E1826 · `--bg-2` 浮起 #2A2233 |
| 金属框 | `--steel` #4A4452 · `--steel-hi` #7A7282 |
| 金 | `--gold` #E9C27A（描边、选中） · `--gold-hi` #FFE3A3（悬停高光） · `--gold-deep` #8A6332（按下） |
| 文字 | `--ink-1` #F6EEDC 主 · `--ink-2` #CFC4B2 次 · `--ink-3` #8F8597 弱 |
| 状态 | `--danger` #E0685A · `--ok` #7BC98A · `--focus` #FFF2A7 |
| 阵营 | 沿用现有 4 个阵营色，只用于选中态和徽记 |

对比度：正文 `--ink-1` / `--ink-2` 在 `--bg-1` 上都 ≥ 7:1 / 4.5:1。

### 1.4 组件（全站一套）

| 组件 | 规格 |
|-|-|
| **框 Frame** | 锻钢边 2px + 内侧 1px 金线 + 四角小角饰（一张 SVG 九宫格），三档：`frame-1` 卡片 / `frame-2` 面板 / `frame-3` 页面主区 |
| **按钮 Button** | 三档且只有三档：<br>• **主按钮**：金色锻造铭牌，展示字 `--t-h3`~`--t-h1`，每屏最多一个<br>• **次按钮**：深钢底 + 金线框，展示字 `--t-h3`<br>• **文字按钮**：无底，悬停出现金色下划线光（返回、取消用这个）<br>状态：悬停（金线变亮 + 内辉光 120ms）、按下（下沉 1px + `--gold-deep`）、禁用（去饱和 40% 不透明）、焦点（`--focus` 2px 外环）。**去掉蓝色珐琅按钮**。 |
| **分区标签 Overline** | 小号加宽字 + 左右各一条渐隐金线，用来分隔「我方」「对手」「战场」 |
| **选择卡 Choice** | 阵营 / 战场 / 难度共用：未选中 `frame-1`，选中时金框加阵营色辉光，右上角徽记 |
| **页面骨架 Page** | 顶栏：左「‹ 返回」文字按钮 · 中/左页面标题（展示字）· 右 声音 / 语言；底栏：右侧主按钮，左侧次要操作。所有二级页同一骨架。 |

### 1.5 动效与声音
- 按钮悬停 120ms、页面切换 200ms 淡入加 8px 上移；`prefers-reduced-motion` 下关闭位移。
- 悬停 / 点击接现有 `sfx.js` 的音效（RTS 菜单的手感很大部分来自声音）。

## 2. 信息架构（改后，2026-11-20 按批注修订）

```
主页（居中，含品牌字标）
   ├─ 开始游戏(主)  ──▶ 人机对战设置：我方(阵营·卡组) │ 对手·电脑(难度) │ 战场 ──开战──▶ 对局
   ├─ 联机游戏      ──▶ 联机对战设置：我方(阵营·卡组) │ 对手·好友(昵称·建房/房号) │ 战场 + 排行榜 ──创建房间──▶ 等待 ──▶ 对局
   ├─ 卡组 · 图鉴 · 设置（一行三个次按钮）
   └─ 进入空间大厅（XR，文字按钮）
```

- **主页居中对称**（批注）：主视觉是左右对称构图（两侧立绘，中间晶石祭坛），菜单放在中轴上，字标在上、菜单面板在下。原方案的左侧竖排与背景不匹配，已改。
- **人机 / 联机两个入口都放主页**（批注）：「开始游戏」= 人机对战，「联机游戏」紧跟其下；两个入口进同一个设置页，模式由入口决定，页内不再有「电脑 / 联机好友」切换。
- **「对局设置」并入开始游戏**（批注）：主页不再单独放「对局设置」；点开始游戏先进设置页（记住上次选择），再点「开战」。代价：从主页到对局多一次点击（1 → 2）。如需保留一键开局，可在设置页之外另加「快速开战」，待定。
- 标题页仍建议取消（批注点 A）。

### 3.4 图鉴 / 设置

## 5. 需要你批注的决定

- **A. 取消标题页？** 建议取消（少一次点击，品牌由主页承担）。
- **B. 备战与联机合并成一屏？** 建议合并（联机只是“对手是谁”的一个选项）。代价是联机流程的界面要重写，风险中等。
- **C. 正文字体：自托管思源黑体，还是用系统字体（微软雅黑 / 苹方）？** 自托管各平台一致，但多下载约 150KB；系统字体零成本。建议**标题自托管、正文用系统字**。
- **D. 展示字体：思源宋体 Heavy + Cinzel？** 也可以选更“游戏”的免费字体（需逐个查授权）。建议先用思源宋体，P0 出效果图再定。
- **E. 材质：去掉蓝色珐琅、保留金色珐琅与紫石？** 建议这样，并把蓝色珐琅换成锻钢次按钮。
- **F. 要不要先做可点击的视觉稿（单个 HTML，不动游戏代码）再进 P0？** 适合先定气质再写样式，约 1–2 小时。
