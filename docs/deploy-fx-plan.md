## 二、设计：两段式「锁定 → 降临」

**1. 锁定（拖牌瞄准时，持续）**：天上有东西在对准这里。
- **地面法阵**替换细圆环：外圈慢转的刻度环 + 内圈反向转的势力符文（用 canvas 画一张贴图，4 个势力各一种纹样，颜色取势力色）+ 中心十字准星。半径仍等于部署半径。
- **天空锁定光束**：从落点正上方约 3 格高处垂下一根很细、半透明、上实下虚的光束，轻微呼吸闪烁，表示「轨道已锁定」。
- **地面压感**：法阵边缘一圈向内收缩的脉冲（每 0.8 秒一次），像在蓄力。
- 不合法：法阵变红、符文停转、光束消失；裂隙内仍是紫色。

**2. 降临（松手出牌那一刻，约 0.6 秒）**：英雄从天而降。
1. **0–0.15s 落雷**：天上一道粗光柱瞬间砸下（比现在粗、长、亮），顶端一团闪光。
2. **0.12s 着陆冲击**：落点一个强闪光 + 一圈快速扩散的冲击波环 + 一圈地面裂纹贴花（淡出 1 秒）+ 扬尘向外推。
3. **0.15–0.6s 余韵**：光柱收窄消散，法阵符文向上飘散成光点，单位在冲击中心出现（单位本身已有出场动画的话，配合它从上往下落 0.3 格）。
4. **镜头**（桌面版）：轻微震屏 0.1 秒（幅度很小，XR 里不震，防晕）。

**分级**：
- 普通单位：完整两段。
- 多只的小兵（`count>2` 的 token，现在只出一个小环）：只要冲击波 + 小闪光，不砸光柱，避免满屏光柱。
- 产兵建筑造出来的：保持现有 `produceFx`，不改。
- 飞行单位：光柱停在空中高度，不出地面裂纹。
- 建筑卡：落雷 + 冲击 + 更重的扬尘。

**音效**：着陆一下低频「咚」+ 高频「嗡」，用现有 `sfx` 系统（若没有合适的就先复用 spawn 的声音）。

## 三、性能约束（WebXR 眼镜 + 手机）

- 只用 additive 混合的平面 / 圆柱 / sprite，不加后处理、不加实时光；粒子总数每次出场 ≤ 30。
- 法阵贴图 4 张 canvas 纹理启动时生成一次、复用；瞄准预览的网格常驻、只改变换和 uniform，不每帧新建。
- 冲击波、裂纹都走 `vfx.add` 的生命周期回收。
- 黑 = 透明（光学透视眼镜）：不用暗色做效果，全部用亮色 additive。
