# 势力平衡调整 · 2026-11

> 目标：第五轮节奏（`PACE` 0.55 / 1.7 / 0.7）之后，四个势力的平均胜率都在 45–55%，任意两两对阵不超过 65 / 35。
> 约束：只改数值（费用、生命、攻击、间隔、被动参数），不改机制、不加新牌，不动 `PACE`。数值都在 `js/cards.js` / `js/game.js`，服务器共用。

## 方法

- **模拟器**：smart AI 对 smart AI。四个势力两两对阵，每对 N 局，双方位置交替；场景固定 starcore；`Math.random` 固定种子；强化阶段双方都选第一项；最长 900 秒。
- **工具**：
  - `tools/balance-sim.mjs <N> [仓库] all`：全势力胜率，已入库；
  - 消融脚本：进程内临时改 `CARDS` 或每局的 `Game` 实例，不改文件。逻辑和 balance-sim 相同，多了"逐项削弱 25%""关掉血祭"和"只跑某一对"三种模式。脚本在会话临时目录，没入库。
- **噪声**：
  - 固定种子时，每改一个数，后面的随机序列就会整体错开。所以同一配置换个 N，某一对的胜率能差 3–7 个百分点。N = 200 时单对胜率的标准误约 3.5%。
  - 迭代时先用 N = 200–300，最终用 **N = 400** 验收（每势力 1200 局）。
- **AI 偏差的局限**：
  - smart AI 的出牌规则是写死的：防守优先、费用判断、法术估值都是启发式。它不会像人一样针对对手调整卡组，也不会刻意保留法力、精细走位。
  - 有些机制它用得比人好，比如混沌血祭每局自动用约 3.5 次；有些比人差，比如钢铁的强化 / 护盾时机、智械的网络站位。
  - 所以这里的结果是"同水平 AI 之间大致公平"，不代表人类对局的胜率。上线后应该看联机对局记录（`game.log` 有出牌记录），再小步修正。
  - 卡组都是推荐卡组（`PRESET_DECKS`），自定义卡组可能有别的强弱关系。

两两对阵（行势力的胜率）：钢铁对智械 40、钢铁对虫群 62、**钢铁对混沌 6**、智械对虫群 25、**智械对混沌 10**、虫群对混沌 27。

### 混沌为什么强

- **血祭（被动）是最大的单项**：关掉血祭后混沌从 85.8% 降到 72.7%（−13 个百分点）。
  - AI 每局用血祭约 3 次，每次少花 1–2 点法力抢节奏，等于凭空多一张牌。
  - 核心生命成本（每点法力 100，冷却 12 秒）相对 2400 的核心太便宜。
- **单卡**：每张牌的生命 / 攻击 / 数值各削弱 25% 做消融，每对 100 局。混沌平均胜率的降幅：

  | 牌 | 降幅 | 原因 |
  |-|-|-|
  | 恶魔构造体（6 费 435 / 56，免控） | −10.6 | 费用效率远高于同档的钢铁坦克（5 费 360 / 30）和智械机甲（5 费 285 / 38） |
  | 吸魂者（35% 吸血、对空） | −9.6 | 远程 + 吸血，打消耗战几乎不掉血 |
  | 自爆邪徒（140 范围伤害） | −7.6 | 2 费换塔血效率高 |
  | 虚空蝠 | −6.3 | |
  | 狂战士 | −5.6 | |
  | 扭曲战士（2 费 31 攻击） | −4.6 | 同费的钢铁步兵只有 16 攻击 |
  | 腐化之雨 | −4.3 | |
  | 灵魂体 | −2.0 | |

- **结论**：混沌的强是"血祭多一张牌 + 每个单位费用效率都高一截"叠加的，没有单一的坏牌。所以要血祭和主力单位一起削。

### 钢铁 / 智械为什么弱

- **钢铁**：步兵 2 费 16 攻击、坦克 5 费 30 攻击，输出太低。军衔被动要存活 10 秒才生效，AI 对局里单位常常活不到。钢铁对虫群本来就占优（62%）：火炮哨站的溅射专克虫群的小怪，所以不能整体加强火炮。
- **智械**：单位生命低（机甲 285、无人机 76），主战单位输出也一般。对虫群（25%）和混沌（10%）双输。

## 最终胜率（两个随机种子各 400 局 / 对，取平均）

| | 钢铁 | 智械 | 虫群 | 混沌 |
|-|-|-|-|-|
| 平均胜率 | **50.0%** | **52.4%** | **50.7%** | **47.0%** |
| 起点 | 36.0% | 31.7% | 46.5% | 85.8% |

| 对阵（前者胜率） | 钢-智 | 钢-虫 | 钢-混 | 智-虫 | 智-混 | 虫-混 |
|-|-|-|-|-|-|-|
| 最终 | 36.5 | **67** | 47 | 42.5 | 51.5 | 61 |
| 起点 | 40 | 62 | 6 | 25 | 10 | 27 |

- 四势力平均胜率都在 45–55%，达标。
- 两两对阵里只有**钢铁对虫群约 67 / 33，略超 65 / 35 的目标**。
  - 原因：AI 对局里，钢铁的火炮溅射、坦克、护盾兵天然克制虫群的小怪海。
  - 能把这一对压下来的改动（削步兵生命、溅射、军旗），都会同时让钢铁对智械掉到 35 以下。噪声约 ±3–4 个百分点，几轮试下来没找到只影响这一对的纯数值改法。
  - 再往下压，大概需要改机制（比如溅射对小体型单位衰减），按约束这次没做。建议上线后看真人对局数据再定。
- 平均每局时长约 173 秒（起点 162 秒）。混沌每局用血祭的次数从约 3 次降到约 2.3 次。
