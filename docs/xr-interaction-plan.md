# XR 出牌交互优化 · Research + Plan（2026-11-20，待批注，don't implement yet）

> 用户反馈：① 捏牌必须碰到，希望远距离 pinch / 射线也能选；② 松手经常没出牌；③ 棋盘进入时太大太近，希望小一点、远一点、低一点；④ 必须低头才看得见手牌，希望能把手牌放到左手（替换菜单位置，菜单先隐藏），或有更好方案。
> 证据来自代码通读（文件:行号），常量均为当前值。

## 1. 现状（Research）

### 1.1 抓牌
- 近抓：拇指-食指距离 < 2.2cm 算捏合（`xr.js:27`），捏合中点离卡中心 **≤ 6cm** 才抓得起（`GRAB_RADIUS`，`xr.js:29`）。卡片 7.2×10cm，捏卡角就会落空；而悬停高亮半径是 7.8cm——**亮了却抓不起**。
- 射线：已经有（手的瞄准射线，`xr-hand-ray.js`），但开启条件很苛刻：手要在头前 10–65cm 的“指向区”、手离卡片要超过 15–22cm（太近就关射线）、同一时间只一只手、射线要在卡上停 0.12s 才认捏合，否则**捏合被吞掉、无反馈**（`xr.js:44-46,1120-1199`）。
- 买不起的牌在战斗中直接抓不起（只弹“法力不足”）。

### 1.2 松手没出牌（逐条排查出的原因）
| # | 原因 | 现在的反馈 |
|-|-|-|
| a | **落点无效就静默飞回**：手比棋盘高 25cm 以上、或投影出界（`xr.js:1332,1398`）。手牌行在棋盘近边外约 20cm，手往前伸不够远时恰好落在这里 | **无提示** |
| b | **松手瞬间手部追踪丢失**：手指张开时拇指/食指关节常短暂丢失 → 直接取消（`xr.js:1079,1094`） | **无提示** |
| c | **射线松手跳点**：张开手指时系统瞄准射线会跳，松手用的是跳后的射线（`xr.js:1220`）；按下时有补偿、松手没有 | 落到别处 / 出界 |
| d | **松手那一帧重新计算落点**：手指张开时捏合中点移动，上一帧还合法的预览这一帧变非法 | 同 a 或提示“不在部署区” |
| e | 部署区 / 石头 / 墙 / 占位 / 法力不足 | 有提示（正常） |

### 1.3 棋盘
- 进入时放在头前 **72cm、低 50cm**，默认“小”尺寸缩放 0.044（约 66×86cm 的台面）（`scene.js:2201`、`xr.js:32`）。双手捏合可拖动 / 旋转，位置会记住。

### 1.4 手牌行为什么要低头
- 手牌行**固定在棋盘近边外侧**，再往下 35°（`cardRowPose`，`xr-math.js:151`）。默认算下来在**视线下方约 66°、离眼 46cm**，远超眼镜视场（约 ±20°），所以必须低头。

### 1.5 左手菜单
- 左手掌心朝向自己 + 手张开 → 弹出：重新居中 / 暂停 / 设置 / 退出 XR / 退出对局。**这是 XR 里进入设置、暂停、退出的唯一入口**，所以“隐藏菜单”前必须给这些功能另找入口。

## 2. 方案（Plan）

### P1 抓牌更宽松（必做）
1. **磁吸抓取**：捏合时取**离捏合点最近的卡**，半径从 6cm 放大到 12cm，并与悬停高亮半径统一（亮了就一定抓得起）。
2. **射线常开、任意距离可选**：去掉“指向区”和“太近就关射线”的限制，对卡片射线一直可用；去掉 0.12s 停留门槛（改为按下那帧的射线快照，已有 `pressRay` 机制）。手离卡近时优先磁吸，远时用射线，两者不再互斥。
3. 买不起的牌也能拿起来比划，落下时再提示“法力不足”（可选，见批注 C）。

### P2 松手必出（必做）
1. **落点锁存**：拖动中记住“最后一次合法落点”；松手时如果当前帧落点无效或抖动，就用最近 150ms 内的合法落点出牌。
2. **追踪丢失宽限**：手指张开瞬间关节丢失不再取消，而是按最后合法落点出牌（150ms 内）；超时才退回。
3. **射线松手防跳**：松手用“开始张开手指前”那一帧的射线命中点。
4. **无效必有反馈**：出界 / 太高时拖动中显示红色“超出战场”提示，松手退回时 toast 说明原因，不再静默。
5. 为 `dragPoint` / `release` 的判定抽出纯函数并补单测（现在 xr.js 这部分零测试）。

### P3 棋盘默认更小、更远、更低（必做，数值可批注）
| | 现在 | 建议 |
|-|-|-|
| 中心距离 | 72cm | **85cm** |
| 高度 | 头下 50cm | **头下 60cm** |
| 默认缩放（小） | 0.044 | **0.038**（台面约 57×74cm） |
| 小 / 中 / 大 | 0.044 / 0.052 / 0.060 | 0.038 / 0.046 / 0.054 |

已经手动拖过棋盘的用户位置会保留；设置里“复位战场”回到新默认。远了以后手够不着，正好由 P1 的射线承担远距离出牌。

### P4 手牌放哪（三选一或组合，**需要你选**）
- **方案 A：手牌抬进视野（推荐作为默认）**。手牌行不再贴着棋盘近边，改为放在**视线下方约 22–25°、离眼约 40cm**、正对视线的位置（仍固定在世界里，不跟头乱晃；转头超过一定角度后缓慢跟随）。不用低头就能看到牌，抬眼就是棋盘。改动最小，和 P1 射线配合最顺。
- **方案 B：手牌放在左手（设置开关，按你的想法）**。开关打开后，左手手腕/掌心上方浮出一排手牌（类似拿着一手牌），右手从左手上捏牌、或射线选牌出牌；左手自己的捏合不会误抓。此时手心菜单隐藏，**设置 / 暂停 / 退出改为手牌行末端的一个小齿轮按钮**（右手点开同样的五个选项）。优点是牌永远在手边、视野里；缺点是左手要一直抬着，打久了会累，且左手追踪丢失时牌会消失。
- **方案 C：手牌跟随视野下缘（HUD 式）**。手牌行始终贴在视野下沿，跟着头走。最省事，但会挡视线、近距离跟头移动容易晕，XR 里一般不推荐。

**我的建议**：默认用 **A**；设置里加 **“手牌位置：桌前 / 左手”** 开关提供 **B**。C 不做。

### P5 设置入口
- XR 设置面板加“手牌位置”一项；2D 设置页 XR 分组同步加一行。
- 选“左手”时：手心菜单停用，入口改为手牌行上的齿轮按钮（见 P4-B）；选“桌前”时保持现有手心菜单。

## 3. 验收
- 单测：新增落点锁存 / 宽限 / 磁吸半径 / 新手牌位姿的纯函数测试，`npm test` 全过。
- 桌面模拟：用现有 XR 调试手段在浏览器里跑抓牌 / 松手路径，确认每种无效松手都有提示。
- **眼镜实测（需要你）**：连续出 20 张牌，统计“松手没出”次数（目标 0，除非确实落在非法区并有提示）；确认不低头可看到手牌；左手模式下打一局。
