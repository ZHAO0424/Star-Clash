# 单位表现修正:整体再缩小 + 重型单位移动卡顿 / 穿模(2026-11-17)

用户原话:「模型在里面的比例还是有点大，然后重族的有些移动动作会一卡一卡的有穿模」。

## 1. 单位整体再缩约 15%

**做法**:`js/unit-size.js` 的 `SIZE_CLASSES` 各档目标高 h 与占地上限 foot 同乘 0.85(档间相对关系不变)。只改渲染缩放;碰撞半径(`UNIT_RADIUS` 0.22)、射程、阵营底环都不动。上一轮分档见 `docs/graphics-pass-1.md`「后续：单位体型分档」。

| 档 | 目标高 h(上一轮 → 现在) | 占地上限 foot |
| --- | --- | --- |
| 虫群小兵 | 0.60 → 0.51 | 0.68 → 0.58 |
| 步兵 | 0.90 → 0.77 | 1.00 → 0.85 |
| 中型 | 1.06 → 0.90 | 1.12 → 0.95 |
| 重型载具 | 0.86 → 0.73 | 1.12 → 0.95 |
| 巨型 | 1.28 → 1.09 | 1.45 → 1.23 |
| 飞行 | 0.78 → 0.66 | 1.12 → 0.95 |
